# voice-stt v0.1.0 — first public release

**Date**: 2026-05-18 · **Tag**: [`v0.1`](https://github.com/fzhiy/voice-stt/releases/tag/v0.1)

voice-to-paste for Windows: hold a PTT hotkey, speak, release — your speech
appears as text in whatever app has focus. Works fully self-hosted (FunASR
Paraformer + Qwen3-ASR on your own GPU) or via an OpenAI-compatible Whisper
gateway.

## Highlights

- **Streaming path** (low latency, primary): FunASR Paraformer-zh-streaming
  live partial captions during dictation + **Qwen3-ASR** (0.6B default, 1.7B
  optional) for the final transcript, over WebSocket.
- **Batch path** (cloud-API-compatible): Whisper Large-v3-turbo via an
  OpenAI-compatible HTTP gateway, with optional Ollama LLM polish for
  filler-word removal and punctuation.
- **Windows client**: AutoHotkey v2 PTT daemon (Shift+Alt+S streaming,
  Shift+Alt+P TTS pronunciation lookup, Shift+Alt+V vocab maintenance),
  warm mic capture with a 300 ms ring-buffer pre-roll (no clipped first
  syllable), WebView2 caption renderer with an Edit-control fallback.
- **Installer + portable**: `install.ps1` for autostart-on-login mode;
  `scripts/build-portable.ps1` produces a `voice-stt-portable.zip` for
  no-install use.
- **Pluggable ASR backend**: the server decouples streaming-partial and
  final-pass behind two narrow ABCs. Switch Qwen3 model size via
  `QWEN3_ASR_PATH`, or disable final-pass entirely via `FINAL_BACKEND=none`.

## Install

- **Installer**: download the ZIP below → extract → double-click
  `install.bat`. Windows SmartScreen warns the first time — the installer
  is unsigned in v0.1; click **More info** → **Run anyway**.
- **From git**:
  ```powershell
  git clone https://github.com/fzhiy/voice-stt
  cd voice-stt
  .\install.ps1
  ```
- **Portable**: extract the ZIP, run `launch.bat` from the unzipped folder.
  No system install, no autostart.

See [`docs/QUICKSTART.md`](https://github.com/fzhiy/voice-stt/blob/v0.1/docs/QUICKSTART.md) for a 5-minute end-to-end setup.

## Self-hosting the GPU server

The streaming server runs FunASR Paraformer + Qwen3-ASR on a Linux GPU
host. Default Qwen3-ASR-0.6B targets 12 GB consumer cards (RTX 4060/4070
Ti class); switch to 1.7B for higher quality on ≥16 GB cards. See
[`server/README.md`](https://github.com/fzhiy/voice-stt/blob/v0.1/server/README.md)
for the install + tuning matrix.

## What's NOT in v0.1 (deferred to v0.2)

- **User-tunable hotkeys** — currently hardcoded Shift+Alt+S/P/V. `.env`
  reading for `HOTKEY_STREAM` / `HOTKEY_TTS` / `HOTKEY_VOCAB` is a v0.2
  task.
- **Native OpenAI Whisper API Bearer auth** — `OPENAI_BASE_URL` may point
  at any OpenAI-compatible gateway, but native `OPENAI_API_KEY` Bearer
  auth (for cloud Whisper providers like Groq, OpenRouter, DeepInfra) is
  deferred.
- **HTTP transport for streaming ASR** — v0.1 is WebSocket-only.
- **Signed installer** — SmartScreen warns on first run. A signed `.msi`
  is a v0.2 candidate (cost: ~$200/yr code-signing cert).
- **Demo GIF / screencast** — coming after the first round of community
  feedback.
- **CI test suite** — there is no GitHub Actions workflow that runs unit
  tests yet (only secret-scan runs). Test infra is a v0.2 task.
- **WebView2 caption renderer support** — Edit-control fallback ships as
  the primary renderer for v0.1; WebView2 is a v0.2 polish item.
